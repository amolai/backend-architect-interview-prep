# Spring Boot – Staff / Principal Engineer Interview Prep

This repository contains **Spring Boot interview preparation material**
for **Staff Engineers, Principal Engineers, and Solution Architects**.

## Scope
- Spring Boot internals
- Auto-configuration
- Configuration & profiles
- Annotations & bean lifecycle
- Spring Data JPA (Boot context)
- Service registry & discovery
- Actuator & production readiness

## What this repo focuses on
- How Spring Boot behaves internally
- Why defaults exist and when they fail
- Production risks and trade-offs
- What interviewers listen for
- Bad answers that signal shallow understanding
